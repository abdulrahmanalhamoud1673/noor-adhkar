# Jordan Bikes — موقع الحجز 🚴

موقع حجز جولات الدراجات لـ Jordan Bikes في عمّان: الزبون يفتح الرابط، يختار اليوم والجولة، يكتب اسمه ورقمه، وياخذ رقم حجز فوراً.

---

## شو في جوّا الموقع؟

| الصفحة | شو بتعمل |
|---|---|
| `index.html` | الموقع الرئيسي: الجولات الأربع، المسارات، الجدول الأسبوعي، الخدمات، الأسئلة، ونافذة الحجز |
| `admin.html` | لوحة الإدارة: كل الحجوزات مرتّبة حسب اليوم والجولة، تأكيد/إلغاء، اتصال وواتساب بضغطة، وتنزيل Excel |

**مميزات الحجز:**
- حجز بثلاث خطوات: الموعد ← المعلومات ← التأكيد
- الجدول الأسبوعي الحقيقي (أي منطقة بأي يوم ووقت) والحجز يتسكّر قبل الجولة بنص ساعة
- «الجولة الجاية» تظهر على الواجهة مع عدّاد
- حصة تدريب للي أول مرة بيركبوا
- رقم حجز فوري + تذكرة + إضافة الموعد للتقويم مع تنبيه قبل ساعة
- «حجوزاتي»: الزبون بيشوف حجوزاته وحالتها (بانتظار التأكيد / مؤكّد)
- رسالة واتساب جاهزة فيها كل تفاصيل الحجز
- بعد الربط بجدول Google: عدّ المقاعد المتبقية، منع الحجز الزايد، منع تكرار نفس الحجز، وإيميل لك مع كل حجز جديد

## تجربته على الكمبيوتر

افتح موجّه الأوامر داخل مجلد `jordan-bikes` ونفّذ:

```bash
python -m http.server 5190
```

ثم افتح `http://localhost:5190`

## تعديل المعلومات — ملف واحد بس

كل شي موجود في **`assets/config.js`**:

- `contact` — رقم الهاتف، واتساب، روابط إنستغرام وثريدز وفيسبوك والخريطة
- `pricing` — سعر الجولة (حالياً 5 د.أ)، مبلغ إضافي للدراجة إذا في، وسعر التدريب
- `booking` — كم يوم للأمام بيقدر الزبون يحجز، أقصى عدد بالجولة، طريقة الدفع
- `periods` — أوقات الجولات الأربع
- `schedule` — الجدول الأسبوعي (أي منطقة بكل وقت لكل يوم)
- `closedDates` — أيام إجازة ما في فيها حجز
- `faq` — الأسئلة الشائعة

> ⚠️ راجع قبل الإطلاق: سعر التأجير والتدريب، وصف المناطق، الأسئلة الشائعة، ورابط الخريطة — كلها مكتوبة كبداية وبتقدر تعدّلها.

## الوضعين: بدون ربط ومع ربط

**بدون ربط (الوضع الحالي):** كل حجز بيطلع للزبون كتذكرة برقم حجز، وبيضغط زر أخضر بيبعتلك تفاصيل الحجز كاملة على واتساب `0776684749`. لوحة الإدارة بهالوضع بتعرض بس حجوزات الجهاز اللي انفتحت منه (للتجربة).

**مع ربط بجدول Google (مجاني):** كل الحجوزات بتنحفظ بجدول Google Sheets تبعك، ولوحة الإدارة بتعرض حجوزات كل الزبائن من أي جهاز، والموقع بيعدّ المقاعد ويمنع الحجز إذا الجولة اكتملت.

---

## ربط الحجوزات بجدول Google — مرة وحدة، 10 دقايق

1. افتح [sheets.new](https://sheets.new) بحساب Google تبع Jordan Bikes — سمّي الجدول «حجوزات Jordan Bikes»
2. من القائمة: **Extensions ← Apps Script**
3. امسح كل الكود الموجود، والصق محتوى ملف **`backend/Code.gs`** كامل
4. فوق بالملف غيّر:
   - `ADMIN_KEY` ← كلمة سر للوحة الإدارة (لازم تتغيّر، اللوحة ما بتفتح بالكلمة الافتراضية)
   - `CAPACITY` ← أقصى عدد أشخاص بالجولة
   - `NOTIFY_EMAIL` ← إيميلك إذا بدك يوصلك إيميل مع كل حجز (اختياري)
5. اضغط 💾 حفظ، ثم من فوق اختار الدالة **`setup`** واضغط **Run** ← وافق على الصلاحيات (Advanced ← Go to project)
6. اضغط **Deploy ← New deployment** ← اختار النوع ⚙️ **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - اضغط **Deploy** وانسخ رابط **Web app URL** (بيخلص بـ `/exec`)
7. افتح `assets/config.js` وحط الرابط هون:
   ```js
   backend: {
     url: "https://script.google.com/macros/s/XXXXXXXX/exec"
   },
   ```
8. خلص ✅ — افتح `admin.html` واكتب كلمة السر.

> إذا عدّلت `Code.gs` بعدين: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** (الرابط بيضل نفسه).

**الجدول نفسه:** كل حجز سطر، فيه رقم الحجز، التاريخ، الجولة، الاسم، الرقم، عدد الأشخاص، والحالة. بتقدر تفتحه من الموبايل بتطبيق Google Sheets كمان.

## لوحة الإدارة `admin.html`

- **فوق:** حجوزات اليوم، اللي بانتظار التأكيد، عدد الراكبين خلال 7 أيام، والإيراد المتوقّع
- **فلترة:** اليوم / بكرا / 7 أيام / القادمة / السابقة / الكل + حسب الحالة + بحث بالاسم أو الرقم أو رقم الحجز
- **كل جولة:** عدد المحجوزين من السعة، وزر نسخ قائمة الأسماء والأرقام (مفيد لمجموعة واتساب)
- **كل حجز:** غيّر الحالة (بانتظار التأكيد / مؤكّد / حضر / لم يحضر / ملغي)، اتصال، وزر واتساب فيه رسالة تأكيد جاهزة للزبون
- **⬇️ تنزيل:** ملف Excel (CSV) بالحجوزات المعروضة

الزبون لما يفتح «حجوزاتي» بيشوف الحالة اللي حطّيتها (مثلاً «مؤكّد») تلقائياً.
