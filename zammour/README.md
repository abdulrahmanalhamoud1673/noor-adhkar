# زمّور 🚗 — بدل ما تزمّر، ابعث رسالة

ستيكر QR على السيارة. أي حدا يمسحه يبعث رسالة لصاحبها **بدون ما يعرف رقمه**، وبدون ما صاحبها يعرف رقم المرسل.

## تشغيل محلي
```bash
npm install
npm run dev      # http://localhost:3000  (الرمز بيظهر على الشاشة بوضع التطوير)
npm test         # فلتر الرسائل + اختبارات API كاملة
```

## الميزات
- رسائل جاهزة بضغطة (فلاشر، ضو، شباك، مسكّرة علي، ...) + نص حرّ اختياري (140 حرف).
- فلتر عربي/إنجليزي: سب، معاكسات، تهديد، أرقام/روابط/حسابات. يتعامل مع التحايل (حروف مفصولة، تكرار، leet، أرقام هندية).
- الرقم والنصوص مشفّرة AES-256-GCM. الـIP ما بنخزّنه (HMAC فقط). الرسائل بتنحذف بعد 30 يوم.
- ردود جاهزة لصاحب السيارة («جاي حالاً»)، وحظر المرسل، وإيقاف مؤقت، وتغيير كود الـQR.
- حدود إرسال، honeypot، Turnstile اختياري، 3 مخالفات = إيقاف مؤقت.
- ستيكر A6 جاهز للطباعة.

## نشر تجريبي بضغطة (Render)
1. ادخل render.com ← **New ← Blueprint** ← اربط GitHub واختر هالمستودع (الملف `render.yaml` جاهز).
2. بعد دقيقتين بيعطيك رابط `https://zammour-xxxx.onrender.com`. الـQR بياخد الرابط تلقائياً.
3. وضع التجربة (`DEMO_MODE=1`) بيعرض رمز الدخول على الشاشة بدل ما يبعثه SMS، والرسائل بتظهر لصاحب السيارة بلوحة التحكم.
ملاحظة: النسخة المجانية بتنام بعد خمول وبتفقد البيانات مع كل نشر. للاستخدام الفعلي استخدم خطة بقرص دائم (`DATA_DIR`) وأزل `DEMO_MODE`.

## الإنتاج
متغيرات البيئة: `NODE_ENV=production`, `BASE_URL`, `ENC_KEY` و`MAC_KEY` (`openssl rand -hex 32` لكل واحد)،
`TRUST_PROXY=1` خلف nginx/Cloudflare، `TURNSTILE_SITE_KEY/SECRET` اختياري.
الإشعارات: `NOTIFIER=twilio-sms` (TWILIO_SID/TOKEN/FROM) أو `NOTIFIER=whatsapp` (WHATSAPP_TOKEN/PHONE_ID/TEMPLATE) — أو أضف مزوّد محلي بـ`server/notify.js`.
ضع الموقع خلف HTTPS دائماً. احفظ مجلد `data/` (SQLite) بنسخ احتياطي.

## ملاحظات الأردن
- أرقام 077/078/079 فقط. شبكات الموبايل تشارك IP (CGNAT) فالحظر مبني على الجهاز مش الـIP.
- قبل الإطلاق: تحقّق من اسم المرسل (Sender ID) وترخيص الـSMS مع هيئة تنظيم قطاع الاتصالات، ومن قانون حماية البيانات الشخصية 2023، وراجع صفحة الخصوصية مع محامٍ.
